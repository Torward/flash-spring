# MyFriend - Пошаговое руководство по запуску

## Предварительные требования

### Системные требования:
- **ОС**: Windows 10/11, macOS, или Linux
- **Android Studio**: версия 4.1.3 или выше
- **JDK**: версия 1.8 или выше
- **Память**: минимум 8GB RAM (рекомендуется 16GB)
- **Свободное место**: минимум 10GB

### Учетные записи:
1. **Google Account** - для доступа к Firebase Console
2. **Agora Account** - для видеозвонков
3. **DeepAR Account** - для AR-фильтров
4. **Stipop Account** - для стикеров
5. **Google Cloud Account** - для Places API

## Шаг 1: Установка и настройка Android Studio

### Установка Android Studio:
1. Скачайте Android Studio с официального сайта
2. Запустите установщик и следуйте инструкциям
3. Установите необходимые компоненты SDK:
   - Android SDK Platform 31
   - Android SDK Build-Tools 30.0.3
   - Android Emulator
   - Android SDK Platform-Tools

### Настройка переменных окружения:
```bash
# Добавьте в PATH:
ANDROID_HOME = C:\Users\Username\AppData\Local\Android\Sdk
JAVA_HOME = C:\Program Files\Java\jdk1.8.0_291
```

## Шаг 2: Клонирование и импорт проекта

### Клонирование проекта:
```bash
git clone <repository-url>
cd Myfriend
```

### Импорт в Android Studio:
1. Откройте Android Studio
2. Выберите "Open an existing Android Studio project"
3. Укажите путь к папке Myfriend
4. Дождитесь завершения синхронизации Gradle

## Шаг 3: Настройка Firebase

### Создание Firebase проекта:
1. Перейдите на [Firebase Console](https://console.firebase.google.com/)
2. Нажмите "Create a project"
3. Укажите название проекта: "Myfriend"
4. Включите Google Analytics (опционально)
5. Завершите создание проекта

### Добавление Android приложения:
1. В Firebase Console выберите ваш проект
2. Нажмите "Add app" → "Android"
3. Укажите:
   - Android package name: `com.spacester.myfriend`
   - App nickname: Myfriend
   - Debug signing certificate (опционально)
4. Скачайте `google-services.json`
5. Замените существующий файл в `app/google-services.json`

### Настройка Firebase Services:
1. **Authentication**:
   - Включите Email/Password и Phone sign-in
   - Настройте шаблоны SMS для OTP

2. **Realtime Database**:
   - Создайте базу данных в режиме тестирования
   - Настройте правила безопасности

3. **Storage**:
   - Создайте хранилище
   - Настройте правила доступа

4. **Cloud Messaging**:
   - Настройте уведомления
   - Получите ключ сервера

## Шаг 4: Настройка API ключей

### Google Maps API:
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите следующие API:
   - Maps SDK for Android
   - Places API
   - Geocoding API
4. Создайте credentials → API key
5. Ограничьте ключ для Android apps
6. Замените ключ в `AndroidManifest.xml`:
```xml
<meta-data
    android:name="com.google.android.geo.API_KEY"
    android:value="YOUR_ACTUAL_API_KEY_HERE" />
```

### Agora SDK:
1. Зарегистрируйтесь на [Agora.io](https://www.agora.io/)
2. Создайте новый проект
3. Получите App ID
4. Добавьте в `app/build.gradle`:
```gradle
implementation 'io.agora.rtc:full-sdk:3.3.1'
```

### DeepAR SDK:
1. Зарегистрируйтесь на [DeepAR](https://www.deepar.ai/)
2. Получите лицензионный ключ
3. Добавьте deepar.aar файл в папку `deepar/`

### Stipop SDK:
1. Зарегистрируйтесь на [Stipop](https://www.stipop.io/)
2. Получите API ключ
3. Добавьте конфигурацию в проект

## Шаг 6: Сборка и запуск

### Сборка проекта:
```bash
# Очистка проекта
./gradlew clean

# Сборка debug версии
./gradlew assembleDebug

# Сборка release версии
./gradlew assembleRelease
```

### Запуск на эмуляторе:
1. Создайте виртуальное устройство в AVD Manager
2. Выберите устройство с API level 23+
3. Запустите приложение через Android Studio

### Запуск на физическом устройстве:
1. Включите USB debugging на устройстве
2. Подключите устройство к компьютеру
3. Разрешите отладку по USB
4. Запустите приложение

## Шаг 8: Настройка для production

### Подписание приложения:
1. Создайте keystore:
```bash
keytool -genkey -v -keystore myfriend.keystore -alias myfriend -keyalg RSA -keysize 2048 -validity 10000
```

2. Добавьте в `app/build.gradle`:
```gradle
android {
    signingConfigs {
        release {
            storeFile file('myfriend.keystore')
            storePassword 'your_password'
            keyAlias 'myfriend'
            keyPassword 'your_password'
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled true
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }
}
```

### Оптимизация производительности:
1. Включите ProGuard/R8
2. Настройте сжатие ресурсов
3. Оптимизируйте изображения
4. Настройте кэширование

### Мониторинг:

2. Настройте Firebase Performance Monitoring
3. Добавьте аналитику событий

## Решение常见问题

### Ошибки сборки:
- **Gradle sync failed**: Очистите проект и перезапустите Android Studio
- **Missing dependencies**: Проверьте подключение к интернету
- **API key errors**: Убедитесь, что все ключи корректны

### Ошибки времени выполнения:
- **Firebase permissions**: Проверьте правила безопасности
- **Network issues**: Проверьте интернет-соединение
- **Camera permissions**: Предоставьте необходимые разрешения

### Производительность:
- **Slow loading**: Оптимизируйте изображения и запросы
- **High memory usage**: Проверьте утечки памяти
- **Battery drain**: Оптимизируйте фоновые процессы
