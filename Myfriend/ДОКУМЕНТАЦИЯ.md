# MyFriend - Документация приложения

## Обзор приложения

MyFriend - это многофункциональное социальное мобильное приложение для Android, разработанное на Java с использованием Firebase. Приложение предлагает широкий спектр возможностей для общения, развлечений и монетизации.

### Основные возможности:
- 📱 Социальная сеть с постами и историями
- 🎥 Видео и голосовые звонки
- 📢 Прямые трансляции и подкасты
- 👥 Группы и чаты
- 🛒 Маркетплейс для продажи товаров
- 🎬 Вечеринки просмотра видео
- 🤳 Фильтры для лица (AR)
- 💰 Система монетизации
- 🔔 Push-уведомления

## Технические характеристики

### Технологический стек:
- **Язык программирования**: Java
- **Минимальная версия Android**: 23 (Android 6.0)
- **Целевая версия Android**: 31 (Android 12)
- **База данных**: Firebase Realtime Database
- **Аутентификация**: Firebase Auth
- **Хранилище**: Firebase Storage
- **Уведомления**: Firebase Cloud Messaging
- **Видеозвонки**: Agora SDK
- **AR-фильтры**: DeepAR SDK
- **Редактор медиа**: PhotoEditor SDK

### Модули проекта:
1. **app** - Основное приложение
2. **deepar** - Модуль AR-фильтров
3. **nativetemplates** - Нативные шаблоны рекламы
4. **SimplePlacePicker-master** - Выбор местоположения
5. **Stipop** - Стикеры и эмодзи

## Ключевые функции

### 1. Аутентификация
- Регистрация по email/паролю
- Регистрация по номеру телефона (OTP)
- Восстановление пароля
- Firebase Authentication

### 2. Главный экран
- Лента постов
- Навигация через BottomNavigationView
- Быстрое меню создания контента
- Система фрагментов (Home, Chat, Profile)

### 3. Медиаконтент
- Создание постов с текстом и медиа
- Короткие видео (рилы) до 1 минуты
- Истории (24 часа)
- Прямые трансляции
- Подкасты
- AR-фильтры для фото/видео

### 4. Коммуникация
- Личные чаты
- Групповые чаты
- Индивидуальные видеозвонки
- Индивидуальные голосовые звонки
- Групповые видеозвонки

### 5. Сообщества

- Модерация контента

### 6. Маркетплейс
- Размещение товаров
- Просмотр товаров

### 7. Вечеринки просмотра

- Чат во время просмотра

### 8. Монетизация
- Система баланса пользователей
- Начисление средств за время в приложении
- Вывод средств

### 9. Настройки
- Темный/светлый режим
- Языковые настройки
- Настройки приватности
- Верификация аккаунта

## Интеграции и SDK

### Firebase Services:
- Firebase Auth - аутентификация
- Firebase Database - база данных
- Firebase Storage - хранилище файлов
- Firebase Messaging - push-уведомления

### Сторонние SDK:
- **Agora SDK** - видеозвонки и трансляции
- **DeepAR SDK** - AR-фильтры
- **PhotoEditor SDK** - редактирование медиа
- **Mapbox** - карты и геолокация
- **Stipop SDK** - стикеры
- **Giphy SDK** - GIF-анимации
- **YouTube API** - интеграция с YouTube
