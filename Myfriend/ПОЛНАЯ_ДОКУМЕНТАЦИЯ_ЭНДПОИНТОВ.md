# MyFriend - Полная документация эндпоинтов Firebase Realtime Database

## Общая структура базы данных

Приложение использует Firebase Realtime Database как бэкенд. Все данные хранятся в виде JSON-дерева со следующей структурой:

```
Root
├── Users
├── Posts
├── Groups
├── Follow
├── Story
├── Reels
├── Product
├── Balance
├── Tokens
├── Live
├── Podcast
├── Party
├── Calling
├── Likes
├── Reaction
├── Saves
├── SavesReel
├── ReportPost
├── ReportReel
├── ReportUser
├── ReportProduct
├── GroupsReport
├── Verification
├── Request
├── Code
├── Admin
├── Ads
├── Chats
├── Location
├── postExtra
├── ReelsLike
├── ReelViews
├── userReport
└── ...
```

## Основные коллекции (эндпоинты)

### 1. Пользователи (Users)
```
/users/{userId}
```
- **GET** `/users/{userId}` - Получить данные пользователя
- **PUT** `/users/{userId}` - Обновить данные пользователя
- **POST** `/users` - Создать нового пользователя

**Поля:**
- `name` - Имя пользователя
- `username` - Никнейм
- `email` - Email
- `phone` - Телефон
- `photo` - Фото профиля
- `cover` - Обложка профиля
- `bio` - Биография
- `website` - Вебсайт
- `verified` - Верификация
- `BlockedUsers` - Заблокированные пользователи
- `High` - Избранные истории
- `Notifications` - Уведомления
- `Count` - Счетчики уведомлений
- `status` - Статус (online/offline)

### 2. Посты (Posts)
```
/posts/{postId}
```
- **GET** `/posts/{postId}` - Получить пост
- **POST** `/posts` - Создать пост
- **DELETE** `/posts/{postId}` - Удалить пост

**Поля:**
- `id` - ID автора
- `text` - Текст поста
- `pTime` - Время публикации
- `type` - Тип поста (text, image, video, bg, meme)
- `vine` - Видео URL
- `meme` - Изображение URL
- `privacy` - Приватность
- `location` - Местоположение
- `Comments` - Комментарии
- `Likes` - Лайки

### 3. Группы (Groups)
```
/groups/{groupId}
```
- **GET** `/groups/{groupId}` - Получить данные группы
- **POST** `/groups` - Создать группу
- **PUT** `/groups/{groupId}` - Обновить группу
- **DELETE** `/groups/{groupId}` - Удалить группу

**Поля:**
- `groupId` - ID группы
- `name` - Название группы
- `gUsername` - Никнейм группы
- `gIcon` - Иконка группы
- `gLink` - Ссылка группы
- `description` - Описание
- `privacy` - Приватность
- `Participants` - Участники
- `Request` - Запросы на вступление
- `Message` - Сообщения
- `Video` - Видеозвонки
- `Voice` - Голосовые звонки
- `Posts` - Посты группы
- `Cover` - Обложка группы

### 4. Подписки (Follow)

```
/follow/{userId}/following/{targetUserId}

```

- **GET** `/follow/{userId}/following` - Получить подписки
- **GET** `/follow/{userId}/followers` - Получить подписчиков

## Правила безопасности Firebase

Пример правил безопасности для базы данных:

```javascript
{
  "rules": {
    "users": {
      "$userId": {
        ".read": "auth != null && auth.uid == $userId",
        ".write": "auth != null && auth.uid == $userId"
      }
    },
    "posts": {
      ".read": "auth != null",
      ".write": "auth != null",
      "$postId": {
        ".validate": "newData.hasChildren(['id', 'text', 'pTime'])"
      }
    },
    "groups": {
      "$groupId": {
        ".read": "auth != null",
        ".write": "auth != null && (data.child('Participants').child(auth.uid).exists() || newData.child('Participants').child(auth.uid).exists())"
      }
    }
  }
}
```

## Аутентификация

Все запросы требуют аутентификации через Firebase Auth. Токен доступа должен передаваться в заголовках.

## Ошибки и статусы

- **200** - Успешный запрос
- **400** - Неверный запрос
- **401** - Не авторизован
- **403** - Доступ запрещен
- **404** - Ресурс не найден
- **500** - Внутренняя ошибка сервера

## Примеры запросов

### Получить данные пользователя:
```java
FirebaseDatabase.getInstance().getReference("Users").child(userId)
    .addListenerForSingleValueEvent(new ValueEventListener() {
        @Override
        public void onDataChange(@NonNull DataSnapshot snapshot) {
            // Обработка данных
        }
    });
```

### Создать новый пост:
```java
HashMap<String, Object> hashMap = new HashMap<>();
hashMap.put("id", userId);
hashMap.put("text", "Текст поста");
hashMap.put("pTime", timestamp);
hashMap.put("type", "text");

FirebaseDatabase.getInstance().getReference("Posts").child(postId)
    .setValue(hashMap);
```

### Подписаться на пользователя:
```java
// Добавить в подписки
FirebaseDatabase.getInstance().getReference("Follow")
    .child(currentUserId).child("Following").child(targetUserId)
    .setValue(true);

// Добавить в подписчики
FirebaseDatabase.getInstance().getReference("Follow")
    .child(targetUserId).child("Followers").child(currentUserId)
    .setValue(true);
```

### Отправить сообщение в чат:
```java
HashMap<String, Object> hashMap = new HashMap<>();
hashMap.put("sender", currentUserId);
hashMap.put("receiver", targetUserId);
hashMap.put("msg", "Текст сообщения");
hashMap.put("timestamp", System.currentTimeMillis());
hashMap.put("type", "text");

FirebaseDatabase.getInstance().getReference("Chats").push()
    .setValue(hashMap);
```

### Сохранить пост:
```java
FirebaseDatabase.getInstance().getReference("Saves")
    .child(currentUserId).child(postId)
    .setValue(true);
```

### Пожаловаться на пост:
```java
FirebaseDatabase.getInstance().getReference("ReportPost")
    .child(postId)
    .setValue(true);
```
